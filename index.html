Análise de Redes Sociais no Brasil

Projeto de análise e visualização de dados com Python, Pandas, Matplotlib, SQLAlchemy e Streamlit

Sobre o Projeto

Este projeto analisa dados simulados de redes sociais no Brasil para identificar padrões de alcance, visualizações, interações e engajamento entre diferentes plataformas e tipos de conteúdo.

Perguntas de Negócio

  • Qual plataforma apresenta maior alcance?
  • Qual plataforma possui maior taxa de engajamento?
  • Quais tipos de conteúdo apresentam melhor desempenho?
  • Como os indicadores evoluem ao longo do tempo?
  • Quais oportunidades podem apoiar decisões de marketing digital?
